## Docs Fundamentals
Course CRS-101. A 45-minute self-paced video course for everyone starting with Docs: creating a workspace, writing and publishing pages, and basic sharing. Free. No prerequisites.

## Shared Documentation Workflows
Course CRS-102. A 90-minute self-paced module for team leads and contributors on templates, review and approval flow, shared spaces and sharing with groups. Free. Prerequisite: Docs Fundamentals (CRS-101).

## Docs Administration and Directory Setup
Course CRS-103. A 60-minute self-paced module for workspace administrators on connecting a directory, groups and permissions. Free. Prerequisite: Docs Fundamentals (CRS-101).

## Rolling Out Shared Documentation Across Teams
Course CRS-104. A 3-hour live workshop for program leads and larger teams (15 or more learners) that plans a rollout, owners and review cadence. Paid. Prerequisite: Shared Documentation Workflows (CRS-102). Sessions run monthly.
